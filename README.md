# FinFlow - Digital Banking System

A full-stack banking application built using Java Spring Boot and MySQL.

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Thunder Client (API Testing)

---

## Modules Completed

### Customer
- Customer Registration
- Customer Login

### Branch
- Create Branch

### Account
- Create Account

### Transactions
- Deposit Money
- Withdraw Money
- Transfer Money

## APIs Implemented

### Customer

- POST /api/customers/register
- POST /api/customers/login

### Branch

- POST /api/branches

### Account

- POST /api/accounts

### Transactions

- POST /api/transactions/deposit
- POST /api/transactions/withdraw
- POST /api/transactions/transfer
